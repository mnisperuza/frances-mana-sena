# Frances y Maná

Base inicial para la landing page de la panadería Frances y Maná.

## Estructura

- `index.html`: marcado semántico de la página.
- `css/styles.css`: tokens visuales y estilos responsive.
- `js/main.js`: JavaScript inicial; puede migrarse a TypeScript cuando se agregue tooling.

Por ahora no requiere dependencias ni proceso de compilación: abre `index.html` en un navegador para visualizarla.
